# 🎂 Age Calculator

A simple and user-friendly Age Calculator application developed using HTML, CSS, and JavaScript. This application calculates a person's age based on their date of birth.

## 🚀 Features

- 🎂 Calculate age using date of birth
- 📅 Select date, month, and year
- 🔢 Display age in years
- 📆 Display age in months
- ⏳ Display age in days
- ⚡ Instant age calculation
- ⚠️ Input validation for invalid dates
- 📱 Responsive design
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Select your date of birth.

5. Click the Calculate button to view the result.
